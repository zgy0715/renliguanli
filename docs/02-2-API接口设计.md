## 一、统一约定

### 1.1 基础路径
- 所有业务接口前缀：`/api`
- 前端开发代理：Vite `3000 → 后端 8000`，浏览器侧始终同源 `/api`
- **生产/云部署**：相对路径，无需修改 baseURL

### 1.2 认证方式
```
Authorization: Bearer <JWT>
```
- 无/无效 token → **HTTP 401**（code 可能为 401，"登录已过期，请重新登录"）
- 角色不足 → **HTTP 403**（前端提示"无权限访问该操作"）
- 唯一免认证接口：`POST /api/auth/login`

### 1.3 统一响应体 `ApiResponse`
| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 0=成功，非0=业务/认证错误 |
| message | String | 提示信息 |
| data | T | 业务数据 |

示例：登录成功
```json
{ "code": 0, "message": "success", "data": { "token": "...", "role": "ADMIN", ... } }
```

### 1.4 权限速查
| 角色 | 缩写 | 说明 |
|---|---|---|
| ADMIN | A | 全部 |
| HR | H | 人事业务 |
| MANAGER | M | 主管（无薪酬、无新增/删除/系统） |
| EMPLOYEE | E | 员工自助 |

## 二、认证 Auth（免认证：登录）

### POST /api/auth/login
| 参数(Body) | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | String | ✅ | |
| password | String | ✅ | |

返回 `data`：`{ token, userId, username, displayName, role, employeeId, expire }`
权限：公开

### GET /api/auth/me
返回 `data`：`{ id, username, displayName, role, employeeId, avatarSeed }`
权限：ADMIN / HR / MANAGER / EMPLOYEE

## 五、员工档案 Employee

### GET /api/employees （分页搜索）
权限：A/H/M
| 参数(Query) | 类型 | 必填 | 默认 |
|---|---|---|---|
| keyword | String | - | 关键词 |
| deptId | Long | - | 部门 |
| status | String | - | ACTIVE等 |
| level | String | - | 职级 |
| education | String | - | 学历 |
| gender | String | - | 性别 |
| tag | String | - | 标签 |
| page | int | - | 1 |
| size | int | - | 10 |

返回 `PageResult<EmployeeVO>`：`{ records, total, page, size }`

### GET /api/employees/tags
权限：A/H/M　|　返回全部员工标签去重列表

### GET /api/employees/{id}
权限：A/H/M　|　返回员工档案详情 Map

### POST /api/employees
权限：A/H　|　Body: Employee　|　新增员工

### PUT /api/employees/{id}
权限：A/H　|　Body: Employee　|　更新员工

### DELETE /api/employees/{id}
权限：A/H　|　删除员工

## 十五、错误码汇总

| HTTP | 场景 | 说明 |
|---|---|---|
| 200 | 成功 | code=0 |
| 400 | 参数错误 | 缺必填 / 格式错误（如缺 month） |
| 401 | 未认证/token 失效 | "登录已过期，请重新登录" |
| 403 | 权限不足 或 未绑定员工 | "无权限访问该操作" |
| 500 | 系统异常 / 智能助手繁忙 | "系统繁忙" |
