# 00 · 功能规格说明书（Spec）

> 文档编号：HRMS-SPEC-001　|　版本：v1.0　|　对应项目：《企业员工管理系统》个人独立完成
> 依据：《AI 生成式软件开发评分标准》第 3.4 节「需求设计阶段要求」

## 一、项目概述

### 1.1 项目名称
**企业员工管理系统（HRMS）**——面向中小企业 HR 的一体化管理平台。

### 1.2 业务场景
企业 HR 部门需要管理组织架构、员工全生命周期档案、考勤、薪酬、绩效、培训、招聘等核心人事事务。传统方式依赖 Excel + 多套系统割裂管理，数据不互通、流程不透明。本系统将分散的人事事务统一到一个平台，并提供**智能助手（自然语言问数）**与**可视化数据分析看板**，帮助 HR 与管理者快速掌握人力数据。

### 1.3 核心功能（一句话）
以 **AI 为引擎、数据为底座** 的全栈 HR 管理平台：覆盖"组织-档案-考勤-薪酬-绩效-培训-招聘"七大业务域，内置数据仓库式分析看板与自然语言智能问数，支持四类角色（管理员/HR/主管/员工）分级权限。

### 1.4 案例特点（用于答辩亮点）
- **AI 智能问数**：通过自然语言（如"各部门有多少员工"）自动生成 SQL/聚合结论 + 图表，降低数据分析门槛；
- **数据驱动决策**：9 大分析维度（组织/九宫格/招聘漏斗/考勤趋势/薪酬成本趋势/能力雷达等）；
- **全生命周期档案**：入职-转正-异动-离职全流程留痕；
- **演示数据完备**：61 名员工、22 个部门、7636 条考勤、399 条薪酬等，开箱即可演示。

## 二、目标与范围

### 2.1 目标
1. 提供可运行的 Web 全栈系统（Vue3 + Spring Boot）；
2. 覆盖 HR 核心业务闭环；
3. 提供 AI 智能问数与可视化分析能力；
4. 满足课堂评分要求的完整工程交付（文档、测试、部署、演示）。

### 2.2 在范围内（In Scope）
| 模块 | 说明 |
|---|---|
| 认证与授权 | 登录、JWT、四角色 RBAC 权限控制 |
| 组织架构 | 部门树、岗位、人员编制 |
| 员工档案 | 增删改查、多条件搜索、标签、档案详情 |
| 考勤管理 | 月度汇总、日历、异常识别、确认归档、排班 |
| 薪酬管理 | 一键核算、工资条、部门成本、确认/发放 |
| 绩效管理 | 考核记录、评级、面谈记录 |
| 培训管理 | 课程库、学习记录 |
| 招聘管理 | 岗位需求、候选人、渠道漏斗 |
| 员工自助 | 我的档案/工资条/出勤/绩效/证明/假期余额 |
| 工作台 | 首页看板、待办、公告 |
| 数据分析 | 9 大分析维度图表 |
| 智能助手 | 自然语言问数 + 图表 |
| 系统管理 | 用户、字典、操作日志 |

### 2.3 不在范围内（Out of Scope）
- 财务/税务对接、银行代发
- 招聘/考勤设备的硬集成（打卡机）
- 移动端 App（仅 Web 响应式）
- 消息推送（邮件/短信）

## 三、角色与权限（RBAC）

| 角色 | 代码 | 说明 | 可访问模块 |
|---|---|---|---|
| 系统管理员 | ADMIN | 最高权限 | 全部模块 + 系统管理（用户/字典/日志） |
| HR 专员 | HR | 人事业务执行者 | 组织/档案/考勤/薪酬/绩效/培训/招聘/智能助手/工作台 |
| 部门主管 | MANAGER | 部门管理视角 | 组织/档案(只读)/考勤/绩效/培训/招聘/智能助手/工作台（**无薪酬**） |
| 普通员工 | EMPLOYEE | 个人自助视角 | 员工自助（我的档案/工资条/出勤/绩效/证明/假期）/培训/公告 |

> 权限在代码中以 `@PreAuthorize("hasAnyRole(...)")` 实现，具体到接口级见《API 接口设计》。

## 四、功能需求详述（按模块）

### 4.1 认证与授权
| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| AUTH-01 | 登录 | 输入用户名/密码，BCrypt 校验，签发 JWT | 正确凭据返回 token 与角色信息；错误提示"用户名或密码错误" |
| AUTH-02 | 获取当前用户 | 携带 token 获取我的信息（含角色/员工绑定） | 返回 userId、role、employeeId 等 |
| AUTH-03 | 会话保护 | 无/无效 token 访问受保护接口返回 401 | 前端跳登录页 |
| AUTH-04 | 权限校验 | 角色不满足接口要求返回 403 | 前端提示"无权限访问该操作" |

### 4.2 工作台（Dashboard）
| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| DASH-01 | 全局概览 | 人数、部门、本月考勤、本月薪酬等汇总卡片 | 数字与演示数据一致 |
| DASH-02 | 人数趋势 | 员工人数月度趋势折线图 | 展示近 N 月趋势 |
| DASH-03 | 薪酬趋势 | 薪酬成本月度趋势 | 展示近 N 月趋势 |
| DASH-04 | 我的待办 | 当前登录人待处理事项列表（审批/转正/合同到期等） | 按人过滤 |
| DASH-05 | 公告 | 最新 10 条已发布公告 | 按发布时间倒序 |

### 4.3 组织架构
| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| ORG-01 | 部门树 | 树形展示部门层级，含人数（含子树）、直属人数、成员列表 | 父部门人数 = 自身 + 全部子部门 |
| ORG-02 | 岗位列表 | 按职级排序的岗位列表 | 返回 code/level/category 等 |

### 4.4 员工档案
| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| EMP-01 | 分页搜索 | 多条件组合：关键词/部门/状态/职级/学历/性别/标签 | 分页返回，默认 10 条/页 |
| EMP-02 | 标签云 | 全部在职员工标签去重列表 | 供筛选使用 |
| EMP-03 | 档案详情 | 单个员工完整信息（含部门/岗位/关系） | 关联字段正确 |
| EMP-04 | 新增员工 | ADMIN/HR 新建档案 | 校验必填项（工号/姓名/部门/岗位等） |
| EMP-05 | 编辑员工 | 更新档案字段 | 保留关系字段 |
| EMP-06 | 删除员工 | 逻辑或物理删除 | 受权限控制 |

### 4.5 考勤管理
| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| ATT-01 | 月度汇总 | 指定月份全员出勤统计（应出勤/实出勤/迟到/早退/加班等） | 需传 `month=YYYY-MM` |
| ATT-02 | 考勤日历 | 指定月份单员工日历视图 | 展示每日状态 |
| ATT-03 | 异常列表 | 迟到/早退/缺卡等异常明细 | 需传 month |
| ATT-04 | 排班 | 班次列表（含弹性/宽限期） | 展示班次信息 |
| ATT-05 | 异常确认 | 对某条考勤记录确认/归档 | 持久化 confirmed 状态 |
| ATT-06 | 我的出勤（自助） | 员工查询本人某月出勤 | 按员工过滤 |

### 4.6 薪酬管理
| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| PAY-01 | 薪酬列表 | 指定月份全员薪酬明细 | 需传 month；含应发/实发/各项扣减 |
| PAY-02 | 薪酬汇总 | 应发/实发/社保/个税合计 | 与明细一致 |
| PAY-03 | 部门成本 | 按部门汇总薪酬成本 | 与明细一致 |
| PAY-04 | 工资条 | 单员工单月明细（税前/税后） | 员工自助可查本人 |
| PAY-05 | 一键核算 | 对某月生成/重算薪酬记录 | 返回生成条数 |
| PAY-06 | 确认/发放 | 更新单条薪酬状态（DRAFT→CONFIRMED→PAID） | 持久化 |

### 4.7 绩效管理
| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| PERF-01 | 绩效列表 | 按期间过滤，排序（期间倒序+得分倒序） | 字段：mode/score/rating/status |
| PERF-02 | 新增绩效 | 创建考核记录（期间/模式/得分/评级/面谈） | 校验期间格式 |
| PERF-03 | 我的绩效（自助） | 员工查本人绩效 | 按员工过滤 |

### 4.8 培训管理
| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| TRAIN-01 | 课程库 | 全部培训课程 | 展示名称/分类/讲师/时长/评分 |
| TRAIN-02 | 学习记录 | 全部或按员工过滤的学习记录 | 含课程名、进度、考试、是否通过 |
| TRAIN-03 | 新增课程 | ADMIN/HR 新建课程 | 校验名称必填 |

### 4.9 招聘管理
| 编号 | 功能 | 描述 | 验收标准 |

| REC-02 | 岗位需求 | 招聘需求列表（含已入职人数） | 按创建时间倒序 |

## 五、非功能需求（NFR）

### 5.1 安全
| 项 | 要求 |
|---|---|
| 密码存储 | BCrypt 哈希，绝不存明文（API 返回脱敏） |
| 认证 | JWT（HS384），过期 24h（`expire=86400000`） |
| 权限 | 后端强制 `@PreAuthorize`，前端仅做菜单隐藏（不信任前端） |
| 会话 | 无/无效 token → 401；权限不足 → 403 |

### 5.2 性能
- 列表接口分页，默认 `page=1, size=10`；
- 组织树/部门人数等聚合一次性查询 + 内存聚合，避免 N+1（代码已优化）；
- 薪酬/考勤查询需传月份避免全表扫。

### 5.3 可用性
- 前端 Vue3 + Element Plus，响应式布局；
- 所有接口统一返回 `{code,message,data}` 结构。

### 5.4 可维护性
- 后端分层：controller / service / repository / domain；
- 数据字典驱动下拉选项（gender/education/status 等）。

### 5.5 演示数据
- 内置 DataSeeder：61 员工、22 部门、7636 考勤、399 薪酬等，保证开箱演示。
