# 03 · 核心功能用户操作路径说明

> 企业员工管理系统 — 五大核心场景操作指引

---

## 场景一 · 高管问数：智能助手

**目标用户**：admin / hr / manager / employee

```mermaid
graph LR
    A[登录] --> B[工作台]
    B --> C[顶部快捷入口<br/>点击「智能助手」]
    C --> D[输入自然语言问题<br/>「各部门多少人」/「平均薪资多少」]
    D --> E[助手返回<br/>自然语言结论 + 图表 + 表格]
    E --> F[点击「推荐追问」<br/>或多轮追问「那最多的呢」]
    F --> G[助手自动续接上一话题<br/>给出深度结论]
    G --> H[定位问题部门<br/>→ 前往员工档案核实]
```

**操作要点**：
1. 登录页点击演示账号 `admin` 一键登录，或手工输入 admin/123456。
2. 工作台顶栏快捷按钮直达智能助手；侧边栏「智能助手」亦可进入；员工账号同样可用（薪资/成本意图自动降级）。
3. 支持「我的考勤 / 我的绩效 / 我的工资」个人自助问答，token 中 `employeeId` 声明直接定位本人数据。
4. 提问返回**结论 + 图表 + 表格 + 推荐追问**四件套，数据来自后端聚合接口；刷新页面后历史对话与图表自动还原。

## 场景二 · HR 管档：员工全生命周期档案

**目标用户**：admin / hr / manager

```mermaid
graph LR
    A[进入「员工档案」] --> B[筛选栏<br/>关键词/部门树/状态/学历/标签]
    B --> C{新增 or 查询}
    C -->|新增| D[点「新增员工」<br/>填写基础信息→保存]
    C -->|查询| E[点击任意员工行]
    E --> F[抽屉详情<br/>基础信息]
    F --> G[切换 Tab<br/>合同管理/教育经历/异动记录]
    F --> H[行内操作<br/>编辑 / 删除]
    D --> I[列表刷新<br/>新员工可见]
```

**操作要点**：
1. 部门使用**树形下拉**，可只看某个中心/部门的下属员工。
2. 点击员工行（头像区）打开**右侧详情抽屉**，四个 Tab 覆盖「基本信息 → 合同 → 教育 → 异动」完整档案。
3. 人才标签按部门/岗位维度筛选，支持「导出当前页 CSV」。
4. 全局搜索框（`Ctrl K`）可直接搜姓名/工号并跳转定位到该员工——详情按 id 直查，**不受列表分页影响**（任意页可定位）。
5. 新增/编辑/删除仅 `ADMIN / HR` 可用，`MANAGER` 仅只读浏览。

## 场景三 · HR 考勤：异常识别与确认归档

**目标用户**：admin / hr / manager

```mermaid
graph LR
    A[进入「考勤排班」] --> B[选择月份<br/>右上角月份选择器]
    B --> C[查看出勤月历<br/>颜色深浅=出勤人数]
    C --> D{发现异常日?}
    D -->|是| E[点击异常格子<br/>查看当日明细]
    D -->|否| F[下方「异常处理」Tab]
    E --> G[异常处理 Tab<br/>逐条确认]
    G --> H[点「确认正常」<br/>状态→已确认]
    G --> I[或点「撤销」]
    F --> J[「月度汇总」Tab<br/>查看个人出勤率/迟到/缺勤]
```

**操作要点**：
1. 月历格子中 **`缺N` 红色、`迟N` 橙色**高亮异常，点击查看当日六类出勤计数。
2. 异常处理列表默认按员工分组展示，`确认正常` 即归档，`撤销` 可回退。
3. 月度汇总按「有异常」优先排序，出勤率用进度条可视化（绿/橙/红三档）。

## 场景四 · HR 算薪：一键核算与工资条

**目标用户**：admin / hr

```mermaid
graph LR
    A[进入「薪酬核算」] --> B[选择核算月份]
    B --> C[右上角「一键核算」]
    C --> D[确认弹窗<br/>覆盖该月已有记录]
    D --> E[后端批量生成<br/>CALCULATED 状态]
    E --> F[查看六大 KPI<br/>应发/实发/五险一金/个税/人均]
    E --> G[成本构成饼图<br/>+ 部门成本柱图]
    E --> H[核算表<br/>按状态 Tab 过滤]
    H --> I[单行「工资条」<br/>抽屉查看应发/扣减/实发]
    H --> J[单行「确认」→「发放」<br/>推进状态流转]
```

**操作要点**：
1. `一键核算` 会**删除该月旧记录并重建**（幂等），适合反复重算演示；**已确认 / 已发放的月份不可重算**（状态机前置校验），避免覆盖已归档数据。
2. 状态流转：`已核算(CALCULATED) → 已确认(CONFIRMED) → 已发放(PAID)`，**必须先确认才能发放**；状态通过独立接口持久化，刷新页面后仍保持。
3. 工资条抽屉内**应发、扣减、实发**三大分区清晰展示五险一金与个税明细。
4. 员工在「员工自助」中也可查看本人工资条。

## 场景五 · 员工自助：查询与申请

**目标用户**：employee（employee1 / 123456）

```mermaid
graph LR
    A[用 employee1 登录] --> B[工作台<br/>个人视角：出勤/工资条/待办]
    B --> C[侧边栏「员工自助」]
    C --> D[档案卡<br/>入职日期/九宫格定位/标签]
    D --> E[Tab1 假期余额<br/>年假/病假/事假/调休]
    D --> F[Tab2 我的考勤<br/>按月查看打卡记录/导出]
    D --> G[Tab3 我的工资条]
    D --> H[Tab4 我的绩效]
    D --> I[Tab5 电子证明<br/>申请在职/收入证明]
    I --> J[填写用途→提交<br/>状态 PENDING]
```

**操作要点**：
1. 员工登录后**工作台自动切换为个人视角**（出勤率/工资条/假期余额），与管理员视角数据隔离。
2. 「我的考勤」支持按月筛选并导出 CSV 打卡记录。
3. 「电子证明」提交后状态为待审批，形成闭环演示。
