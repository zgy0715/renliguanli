## 一、设计概览

### 1.1 数据库选型
| 环境 | 数据库 | 说明 |
|---|---|---|
| 本地/云端（默认） | **H2 内存库** | `jdbc:h2:mem:hrms`，`ddl-auto: create-drop`，启动自动建表并灌入演示数据，零依赖开箱即用 |
| 可选生产 | **MySQL 8** | 提供 `application-mysql.yml` profile 切换（`ddl-auto: update`） |

> 连接参数含 `NON_KEYWORDS=VALUE,TYPE,LEVEL,STATUS`，规避 H2 保留字导致建表失败的问题（如 `sys_dict` 表）。

### 1.2 ORM 与建表方式
- Spring Data JPA + Hibernate，实体类自动建表（`ddl-auto`）；
- 主键统一 `BIGINT AUTO_INCREMENT`（`IDENTITY` 策略）；
- 表名/字段名与实体一致（Hibernate 默认命名策略，无驼峰转下划线）。

## 二、ER 关系总览

```
sys_user ──(employeeId)──▶ employee
department ──(parentId)──▶ department（自关联树）
department ──(leaderId)──▶ employee（部门负责人）
employee ──(department)──▶ department
employee ──(position)────▶ position
employee ──(managerId)───▶ employee（直属上级）
employee ◀──(employeeId)── attendance_record / payroll_record /
                            perf_record / train_record / hr_certificate /
                            leave_request / emp_education / emp_contract / emp_transfer
recruit_candidate / recruit_job：招聘域独立
train_course ◀──(courseId)── train_record
sys_dict / sys_operation_log / hr_todo / hr_announcement：基础/公共域
```

## 五、关键查询设计（含索引）

| 查询 | 表 | 策略 |
|---|---|---|
| 员工分页搜索 | employee | 组合过滤 + 分页（PageResult） |
| 部门树人数（含子树） | department + employee | 一次性取在职员工按部门分组，内存自底向上累加 |
| 考勤月度汇总 | attendance_record | `month` 转 [月初,月末] 区间查询 |
| 薪酬按月度 | payroll_record | `payMonth` 精确查询 |
| 自助我的数据 | 各表 | 统一按 `employeeId` 过滤 |

已建索引：`perf_record(employee_id)`、`train_record(employee_id)`、`hr_todo(assignee_id, status)`。
