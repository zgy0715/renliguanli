# 项目介绍文档

> 2607-3 单人组 · 第十七组 · 赵广雨

---

## 一、项目名称

**企业员工管理系统（HRMS · Human Resource Management System）**

面向中小型企业的一体化人力资源数字化平台，覆盖员工全生命周期「选、用、育、留」的完整业务闭环。

## 二、业务场景

某快速成长的中型企业（约 60 人规模、22 个部门），人事管理面临典型痛点：

| 痛点 | 场景描述 | 系统解法 |
|---|---|---|
| 事务割裂 | 员工信息在 Excel、纸质档案、多个工具间分散维护，口径不一 | 一套平台统一管理组织、档案、考勤、薪酬、绩效、培训、招聘 |
| 数据滞后 | 月度报表靠人工汇总，管理层看到的永远是"上个月" | 实时看板 + 智能助手自然语言问数，随问随答 |
| 决策无据 | 招聘渠道哪家强、哪些部门人效低、人才分布如何，全凭感觉 | 招聘漏斗、部门人效、人才九宫格等 9 维数据分析 |
| 协作低效 | 请假、开证明、查工资条都要跑 HR 办公室 | 员工自助：假期余额、电子工资条、电子证明在线申请 |
| 权限混乱 | 薪酬等敏感数据全员可见，存在泄露风险 | RBAC 四级角色，菜单 / 接口 / 数据三重收敛 |

**四类角色各有专属视角**：

- **系统管理员（admin）**：全部功能 + 用户与权限、数据字典、审计日志
- **HR 专员（hr）**：人事全模块操作，含算薪与绩效管理
- **部门主管（manager）**：本部门相关数据查看与团队管理
- **普通员工（employee）**：个人工作台 + 自助服务（我的考勤 / 工资条 / 绩效 / 假期）

## 三、核心功能

系统共 **8 大业务模块 + 1 个智能助手**：

| 模块 | 核心能力 |
|---|---|
| 🏢 组织人事 | 三级部门树、P/M 双序列岗位体系、编制管理、组织成员下钻 |
| 📋 员工档案 | 全生命周期档案（合同 / 教育 / 异动 Tab）、人才标签、完档度评分 |
| 📅 考勤排班 | 班次配置、出勤月历热力图、迟到 / 早退 / 缺勤自动识别、月度汇总与一键归档 |
| 💰 薪酬核算 | 一键批量算薪（幂等可重跑）、五险一金与个税、成本构成分析、工资条、`DRAFT→CALCULATED→CONFIRMED→PAID` 状态机 |
| 🎯 绩效管理 | OKR / KPI / 360 多模式考核、评级分布、人才九宫格（潜力 × 绩效） |
| 🎓 培训发展 | 12 门课程库、学习记录、能力雷达图 |
| 🧲 招聘管理 | 岗位需求、候选人六阶段漏斗（简历→入职）、渠道效能分析 |
| 🧑‍💼 员工自助 | 个人档案卡、假期余额、我的考勤 / 工资条 / 绩效、电子证明在线申请闭环 |
| 🤖 **智能助手** | **自然语言问数**：问「各部门多少人」「平均薪资多少」，返回结论 + 实时图表 + 推荐追问；支持多轮追问与个人自助问答，按角色收敛敏感数据 |

## 四、案例特点

1. **AI 智能助手（核心创新）**：内置规则式 NLP 意图引擎（18 类意图、关键词 + 同义词 + 部门名校对），零外部 LLM 依赖、结果确定可测；从"被动看板"升级为"主动问数"。
2. **可复现的演示数据**：`Random(42)` 固定随机种子 + `create-drop` 启动重建，任何机器一键复现同一套 61 员工 / 7636 考勤 / 399 薪酬的完整演示环境。
3. **前后端分离全栈**：Spring Boot 3（Java 17 / JPA / Security / JWT）+ Vue 3（TypeScript / Element Plus / ECharts / Pinia），H2 内嵌库零配置启动，MySQL 可选切换。
4. **一键启动与云端部署**：`./start.sh` 一键构建启动全栈；`.cloudstudio.yml` 支持 CloudStudio 云 IDE 导入即运行，生成公网预览链接随时访问。
5. **安全体系完整**：JWT 无状态认证、BCrypt 密码哈希、`@PreAuthorize` 方法级 RBAC、XSS 实体转义、CORS 白名单、操作审计留痕。
6. **工程质量内建**：51 个接口测试用例（92% 通过率）、vue-tsc 全量类型校验零告警、多代理并行回归验证 60+ 接口、文档与提交全程留痕（46 次 Git 提交）。
