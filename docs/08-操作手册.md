## 一、启动与访问

### 方式一：本地一键启动（推荐）

环境要求：JDK 17+ · Node.js 18+（脚本会按需自动安装缺失工具）

```bash
chmod +x ./start.sh && ./start.sh
```

脚本自动完成：构建后端 jar → 启动后端（端口 8000，H2 内嵌库免装 MySQL）→ 安装前端依赖 → 启动前端（端口 3000）。

启动完成后访问 **http://localhost:3000**，`Ctrl + C` 一键停止全部服务。

### 方式二：CloudStudio 云端访问

仓库已含 `.cloudstudio.yml`，在 [cloudstudio.net](https://cloudstudio.net/) 从 Git 仓库导入后自动启动，复制预览链接（形如 `https://xxxx--3000.ap-shanghai2.cloudstudio.club/`）即可在任意浏览器访问。

### 方式三：本地分步启动（开发调试）

```bash
# 后端（默认 H2；如需 MySQL 加 -Dspring-boot.run.profiles=mysql）
cd backend && mvn spring-boot:run
# 前端
cd frontend && npm install && npm run dev
```

> 首次启动自动建表并灌入演示数据（约 20 秒），数据固定种子、完全可复现；重启后数据自动重建。

## 三、各模块操作说明

### 1. 工作台（数据驾驶舱）

登录后默认进入。顶部为 KPI 卡片（在职人数 / 本月出勤率 / 薪酬总成本等），下方为可视化图表（人员趋势、人力结构、部门规模、人才九宫格等）。

- 切换右上角**月份**可查看不同时期数据
- 点击「智能助手」快捷按钮直达问数

### 2. 智能助手（★ 核心功能）

侧边栏「智能助手」进入，直接用**中文提问**：

- 「各部门有多少员工」→ 返回结论 + 柱状图 + 推荐追问
- 「平均薪资多少」（admin/hr 可见）→ 公司均薪与分布
- 「那最多的呢」→ 自动续接上一话题，多轮追问
- 「我的考勤 / 我的绩效 / 我的工资」→ 个人自助问答（任意角色可用）

刷新页面后对话历史与图表自动还原；普通员工问薪资 / 成本类问题会自动降级为友好提示，敏感数据不越权。

### 3. 组织架构

- 左侧部门树：节点显示部门与**人数**，点击节点直接展开该部门在职成员（姓名 / 工号 / 岗位 / 职级）
- 顶部可切换「组织树 / 岗位体系」视图，岗位分 P（专业）/ M（管理）双序列

### 4. 员工档案

- 筛选栏支持关键词 / 部门树 / 状态 / 学历 / 标签组合查询
- **点击任意员工行**打开右侧详情抽屉：基础信息 + 合同 / 教育 / 异动三个 Tab
- 「新增员工 / 编辑 / 删除」仅 ADMIN / HR 可见（MANAGER 只读）
- 顶部全局搜索（`Ctrl + K`）输入姓名或工号，可跨模块直接定位员工详情（不受列表分页影响）
- 支持导出当前页 CSV

### 5. 考勤排班

- 右上角选择月份，查看**出勤月历热力图**（颜色深浅 = 出勤人数；`缺N` 红色、`迟N` 橙色高亮异常日）
- 点击异常日格子查看当日六类出勤计数明细
- 「异常处理」Tab 逐条**确认正常**（归档）或**撤销**
- 「月度汇总」Tab 按员工查看出勤率 / 迟到 / 缺勤，出勤率进度条三色分档

### 6. 薪酬核算（admin / hr）

- 选择核算月份 → 右上角**一键核算** → 确认弹窗后批量生成（幂等：重算会覆盖该月旧记录）
- 顶部六大 KPI 联动：应发 / 实发 / 五险一金 / 个税 / 人均成本
- 图表区：成本构成饼图 + 部门成本柱图
- 核算表按状态 Tab 过滤；单行操作：
  - **工资条**：抽屉查看应发 / 扣减 / 实发明细
  - **确认 → 发放**：状态机 `已核算 → 已确认 → 已发放`，必须先确认才能发放，已确认 / 已发放月份不可重算

### 7. 绩效管理

- 绩效列表按周期 / 部门 / 评级筛选；评级分布图（A/B/C/S）
- **人才九宫格**：潜力（1-9）× 绩效（A/B/C/S）映射 3×3 热力图，一眼定位核心骨干与风险人群

### 8. 培训发展

- 课程库 12 门课程，卡片式展示
- 学习记录按状态（已完成 / 进行中 / 未开始）跟踪，能力雷达图展示技能分布

### 9. 招聘管理

- **招聘漏斗**：候选人六阶段（简历筛选→初试→复试→HR 面→Offer→入职）逐层转化
- 漏斗上方渠道按钮（官网 / BOSS 直聘 / 内推…）一键过滤；按钮列表取自全量候选，过滤后可随时切回
- 渠道效能视图对比各渠道 Offer 率

### 10. 员工自助（全员）

- 个人档案卡：入职信息、九宫格定位、人才标签
- 我的考勤 / 我的工资条 / 我的绩效 / 假期余额（仅统计已审批年假）
- **电子证明在线申请**：提交后进入 PENDING 待审批状态，HR 处理后闭环

### 11. 系统管理（admin）

- 用户管理：账号的启用 / 停用与角色分配
- 数据字典：全局枚举值维护
- 操作审计日志：关键操作留痕可查

## 五、常见问题（FAQ）

**Q1：登录提示「无权限访问该操作」？**
先确认账号密码（均为 123456）；若在云端部署遇到，通常是服务未启动或后端 CORS 白名单未放行预览域名——按 `README.md` 问题表 #34 排查，或改用 admin 账号重试。

**Q2：重启后数据没了？**
演示环境使用 H2 内存库 + `create-drop`，重启自动重建**同一套**演示数据（固定随机种子），属预期行为，无需备份。

**Q3：一键核算后想重算？**
仅「草稿 / 已核算」状态月份可重算；已确认 / 已发放月份受状态机保护，防止覆盖归档数据。

**Q4：普通员工看不到薪酬 / 组织等菜单？**
RBAC 设计如此：employee 角色菜单自动收敛为工作台 / 自助 / 培训 / 智能助手；薪资数据可问助手「我的工资」获取本人工资条。

**Q5：云端访问白屏或接口不通？**
按 `README.md` 问题表 #32 / #33 排查：确认 start.sh 已执行、3000/8000 端口在监听、代码为最新版本（旧进程需先 `pkill -f java; pkill -f vite`）。
